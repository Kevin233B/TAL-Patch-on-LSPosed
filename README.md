# TAL-Patch on LSPosed
# 本项目将归档，但不代表停更，往后更新将闭源发布
由于这个项目，我受到了来自一群喜欢玩云游戏的小屁孩的语言攻击。\
本项目往后将闭源发布，若情况更糟糕，可能转为收费制。\
感谢您使用TAL-Patch on LSPosed。\
TAL-Patch on LSPosed由TAL-Patch on Magisk而来，最初的开发原因是为了解决TalPad在OS4.0.0之后修改PMS导致TAL-Patch on Magisk不再通用的问题。\
TAL-Patch on LSPosed支持恢复通知内容、伪装学习时长与锁定桌面启动器等一系列功能。
# 关于隐蔽性
LSPosed模块天生便带着可检测性，因此比起TAL-Patch on LSPosed，我们更优先考虑TAL-Patch on Zygisk，但本模块开发闭源时期，使用Zygisk模块进行Hook系统框架与应用进程的操作并未流行。
